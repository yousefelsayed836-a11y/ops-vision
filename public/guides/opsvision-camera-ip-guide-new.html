دليل ربط كاميرا المغسلة

اتبع الخطوات التالية لإضافة كاميرا IP وربطها بالحوض الصحيح في نظام OpsVision.

1افتح إعدادات الكاميرا

من تطبيق الكاميرا افتح شاشة IP / Domain ثم اضغط Add.

2أدخل بيانات الكاميرا

املأ الخانات كالتالي:

  • Alias: اسم مختصر مثل Wash 1
  • IP Address: عنوان الكاميرا داخل الشبكة مثل 192.168.1.10
  • Port: المنفذ المكتوب في إعدادات الكاميرا، وغالبًا 8000
  • User Name: اسم مستخدم الكاميرا
  • Device Password: كلمة مرور الكاميرا

3احفظ الكاميرا

اضغط Add وانتظر ظهور الكاميرا بحالة متصلة. إذا لم تتصل، تأكد أن الهاتف والكاميرا على الشبكة نفسها وأن الـ IP صحيح.

4أدخل الكاميرا في النظام

سجّل الدخول إلى OpsVision ثم افتح:

إعدادات المغسلة ← IP الكاميرا

اختر الحوض، اكتب عنوان IP الخاص بالكاميرا، ثم اضغط حفظ.

5اختبر الربط

افتح صفحة الكاميرات وتأكد من ظهور الحالة متصلة. إذا كانت الكاميرا تغطي أكثر من حوض، أدخل نفس IP لكل حوض واضبط مكان الحوض من خيار تحديد مكان الحوض في صورة الكاميرا.

مهم: لا ترسل كلمة مرور الكاميرا في الرسائل. استخدمها فقط داخل إعدادات الكاميرا والنظام.
